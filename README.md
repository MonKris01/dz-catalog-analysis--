# Анализ каталога фильмов

Учебный проект по ручному анализу каталога на Python без `pandas`, `numpy` и других библиотек анализа данных.

## Запуск

```bash
uv sync
uv run catalog_analysis.py
uv run ruff check .
```

Основная точка входа — `build_report(movies)`. В файле также реализованы функции всех девяти этапов задания.
